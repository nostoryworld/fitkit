# 🧰 FitKit

**Paste any job posting + your CV → get a tailored application kit in seconds.**

Live demo: **https://fitkit.odemakindeezekiel5.workers.dev**

FitKit analyzes a job posting against your CV and produces three things:

1. **📊 Skills-match analysis** — a 0–100 fit score, skills you have (matched) vs. skills the posting wants that you don't (missing), plus an honest 2–3 sentence assessment.
2. **✍️ Rewritten CV bullets** — 5–7 bullets rewritten in the posting's own language, quantified where your CV supports it. The AI is instructed to never invent experience you don't have.
3. **💌 Cover letter draft** — a tight, under-250-words letter mapping your proof points to the role.

Built for the [DEV Hacktoberfest Open-Source AI Challenge](https://dev.to/challenges) (Week 3, Oct 2026).

## Open-weight AI at its core

Every kit is generated by **Llama 3.1 8B (FP8)** — a fully open-weight Meta model — running on **Cloudflare Workers AI** (free tier, $0). There is no API key, no external AI vendor, no database.

How it works: `POST /api/analyze` sends one structured system prompt (persona + strict JSON schema + truthfulness rules: *never invent jobs, skills, or credentials*) plus the posting and CV to the model. The worker parses the JSON, validates its shape, and the UI renders the three sections. If the model ever returns malformed output, the API fails closed with a clean retry message instead of showing garbage.

## Project structure

```
src/
  worker.ts   # Cloudflare Worker: serves the UI + POST /api/analyze → Workers AI
  ui.html     # Single-page mobile-first UI (inline CSS/JS, no framework)
dist/
  worker.js   # esbuild bundle (generated)
wrangler.toml # Worker config (AI binding, compat date)
```

## Run it locally

Requirements: Node 18+, a Cloudflare account with Workers AI enabled (free tier is enough).

```bash
npm install
npx esbuild src/worker.ts --bundle --format=esm \
  --outfile=dist/worker.js --loader:.html=text
npx wrangler dev        # serves locally; needs `wrangler login`
```

Deploy (same pattern this demo used — raw Workers API, no extra accounts):

```bash
npx wrangler deploy     # or upload dist/worker.js via the scripts API with an `ai` binding
```

## API

`POST /api/analyze` — `{ "jobText": "...", "cvText": "..." }` (each truncated at 8000 chars, min 50 chars)

→ `{ "kit": { "match": { "score", "matched", "missing", "summary" }, "bullets": [...], "coverLetter": "..." }, "model": "@cf/meta/llama-3.1-8b-instruct-fp8" }`
